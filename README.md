# 📊 People Analytics Dashboard

Dashboard interativo desenvolvido em **Python** com **Streamlit**, voltado para análise de dados de Recursos Humanos (RH). O projeto explora indicadores de desempenho, turnover, absenteísmo e distribuição de colaboradores por departamento e cargo.

---

## 🚀 Demonstração

Dashboard interativo com filtros por departamento e visualizações dinâmicas.

---

## 🧠 Objetivo do Projeto

Este projeto tem como objetivo simular um ambiente de **People Analytics**, permitindo a análise de indicadores estratégicos de RH para apoio na tomada de decisão.

---

## 📌 Principais Métricas

- 👥 Total de colaboradores ativos  
- 🔁 Taxa de turnover  
- 📉 Absenteísmo médio  
- 📊 Desempenho médio  
- 😊 Satisfação média  
- 🧑‍💼 Distribuição por cargo  
- 🏢 Distribuição por departamento  

---

## 📊 Visualizações

O dashboard contém gráficos interativos criados com **Plotly**:

- Pizza: colaboradores por departamento  
- Barras: desligamentos por departamento  
- Barras horizontais: cargos mais comuns  
- Barras: desempenho por departamento  
- Barras: satisfação por departamento  

---

## 🛠️ Tecnologias Utilizadas

- Python
- Streamlit  
- Pandas  
- Plotly  
- NumPy  

---

## ⚙️ Como Executar o Projeto

### 1. Clone o repositório

```bash
git clone https://github.com/gildemardiniz/streamlit_rh_dashboard.git 
```
### 2. Acesse a pasta
```bash
cd streamlit_rh_dashboard
```
### 3. Instale as dependências
```bash
pip install -r requirements.txt
```
### 4. Execute o app
```bash
streamlit run streamlit_rh_dashboard.py
```
